Introducción a Grid Column y Grid Row

Las propiedades grid-column y grid-row son fundamentales en CSS Grid Layout, ya que te permiten controlar la posición y el tamaño de los elementos dentro de una cuadrícula.

Tip: CSS Grid Layout es un sistema de diseño bidimensional que te permite crear diseños complejos y responsivos de manera fácil y mantenible.

¿Qué son estas propiedades?

  • grid-column: Define en qué columnas de la cuadrícula se colocará un elemento.
  • grid-row: Define en qué filas de la cuadrícula se colocará un elemento.

Sintaxis básica

.item {
  grid-column: inicio / fin;
  grid-row: inicio / fin;
}

Ejemplo Visual

En este ejemplo, puedes ver cómo las propiedades grid-column y grid-row controlan la posición y tamaño de los elementos:

.item1 {
  grid-column: 1 / 3;  /* Desde la línea 1 hasta la 3 */
  grid-row: 1;         /* Solo la fila 1 */
}

.item2 {
  grid-column: 3 / 5;  /* Desde la línea 3 hasta la 5 */
  grid-row: 1 / 3;     /* Desde la línea 1 hasta la 3 */
}

.item3 {
  grid-column: 1;      /* Solo la columna 1 (equivalente a 1 / 2) */
  grid-row: 2 / 4;     /* Desde la línea 2 hasta la 4 */
}

.item4 {
  grid-column: 2 / 4;  /* Desde la línea 2 hasta la 4 */
  grid-row: 3;         /* Solo la fila 3 */
}

.item5 {
  grid-column: 4;      /* Solo la columna 4 */
  grid-row: 3;         /* Solo la fila 3 */
}

Formas Alternativas de Especificar Valores

Sintaxis Explicación Ejemplo
inicio / fin Especifica las líneas de inicio y fin grid-column: 2 / 4
inicio / span valor Especifica la línea de inicio y cuántas celdas abarcar grid-row: 2 / span 3
span valor / fin Especifica cuántas celdas abarcar y la línea de fin grid-column: span 2 / 5
span valor Abarca un número específico de celdas desde la posición actual grid-row: span 2
auto Colocación automática según el algoritmo de grid grid-column: auto

Casos de Uso Comunes

Diseño de Cabecera

Crear una cabecera que ocupe todo el ancho:

.header {
  grid-column: 1 / -1;  /* Desde la primera hasta la última línea */
  grid-row: 1;
}

Barra Lateral

Una barra lateral que ocupa varias filas:

.sidebar {
  grid-column: 1;
  grid-row: 2 / 5;  /* Desde la fila 2 hasta la 5 */
}

Elemento que Abarca Múltiples Columnas

Un elemento destacado que ocupa dos columnas:

.featured {
  grid-column: span 2;  /* Abarca 2 columnas */
  grid-row: 3;
}
