📐 CSS Grid - Definiciones Claras

Separación visual para mejor comprensión

🗺️ Definición de Áreas

Crea layouts semánticos con nombres de áreas para un código más legible y mantenible.

Contenedor Principal

.container { display: grid; grid-template-areas: "header header header" "sidebar content content" "footer footer footer"; gap: 15px; min-height: 100vh; }

Asignación de Áreas a Elementos

/* Cada elemento hijo se asigna a un área específica */
.header { grid-area: header; } .sidebar { grid-area: sidebar; } .content { grid-area: content; } .footer { grid-area: footer; }
💡 Tip: Los nombres de áreas pueden ser cualquier palabra descriptiva que represente la sección de tu layout.

⚖️ Alineación del Contenedor

Controla cómo se distribuye el espacio sobrante alrededor de los elementos del grid.

Alineación Horizontal (Eje Principal)

.container { justify-content: start; /* Alinea a la izquierda */ justify-content: end; /* Alinea a la derecha */ justify-content: center; /* Centra horizontalmente */ justify-content: stretch; /* Estira para llenar el espacio */ justify-content: space-around; /* Espacio alrededor de los items */ justify-content: space-between; /* Espacio entre los items */ justify-content: space-evenly; /* Espacio uniforme alrededor */ }

Alineación Vertical (Eje Cruzado)

.container { align-content: start; /* Alinea arriba */ align-content: end; /* Alinea abajo */ align-content: center; /* Centra verticalmente */ align-content: stretch; /* Estira para llenar el espacio */ align-content: space-around; /* Espacio alrededor de los items */ align-content: space-between; /* Espacio entre los items */ align-content: space-evenly; /* Espacio uniforme alrededor */ }
💡 Nota: Estas propiedades funcionan cuando el grid es más pequeño que su contenedor y hay espacio sobrante para distribuir.

🎯 Alineación de Items

Controla cómo se alinean los elementos individuales dentro de sus celdas del grid.

Alineación Global de Todos los Items

.container { /* Alineación horizontal de todos los items */ justify-items: start; /* Alinea a la izquierda de su celda */ justify-items: end; /* Alinea a la derecha de su celda */ justify-items: center; /* Centra horizontalmente en su celda */ justify-items: stretch; /* Estira para llenar la celda (default) */
/* Alineación vertical de todos los items */ align-items: start; /* Alinea arriba de su celda */ align-items: end; /* Alinea abajo de su celda */ align-items: center; /* Centra verticalmente en su celda */ align-items: stretch; /* Estira para llenar la celda (default) */ }

Alineación Individual de Items

.item { /* Alineación horizontal individual */ justify-self: start; /* Alinea este item a la izquierda */ justify-self: end; /* Alinea este item a la derecha */ justify-self: center; /* Centra este item horizontalmente */ justify-self: stretch; /* Estira este item */
/* Alineación vertical individual */ align-self: start; /* Alinea este item arriba */ align-self: end; /* Alinea este item abajo */ align-self: center; /* Centra este item verticalmente */ align-self: stretch; /* Estira este item */ }
💡 Diferencia clave: justify-items/align-items se aplican al contenedor y afectan a TODOS los items. justify-self/align-self se aplican a items individuales para sobrescribir la alineación global.
