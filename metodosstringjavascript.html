🔤 Strings en JavaScript

Guía completa de métodos para manipulación de texto

🔄

Conversión de Case

toUpperCase()
Convertir a MAYÚSCULAS
let texto = "Hola Mundo";
texto.toUpperCase(); // "HOLA MUNDO"
toLowerCase()
Convertir a minúsculas
let texto = "Hola Mundo";
texto.toLowerCase(); // "hola mundo"
toString()
Convertir a string
let numero = 123;
numero.toString(); // "123"
🔍

Búsqueda en Strings

indexOf()
Encontrar posición de substring
let texto = "Bienvenido a JavaScript";
texto.indexOf("Java"); // 13 texto.indexOf("Python"); // -1
includes()
Verificar si contiene substring
let texto = "Aprendiendo JavaScript";
texto.includes("Java"); // true texto.includes("PHP"); // false
startsWith()
Verificar si comienza con substring
let texto = "Hola Mundo";
texto.startsWith("Hola"); // true texto.startsWith("Mundo"); // false
endsWith()
Verificar si termina con substring
let texto = "archivo.js";
texto.endsWith(".js"); // true texto.endsWith(".php"); // false
search()
Buscar con expresión regular
let texto = "JavaScript es genial";
texto.search(/Java/); // 0 texto.search(/php/i); // -1
✂️

Modificación de Strings

trim()
Eliminar espacios en blanco al inicio y final
let texto = " hola mundo ";
texto.trim(); // "hola mundo"
replace()
Reemplazar texto
let texto = "Me gusta Java";
texto.replace("Java", "JavaScript"); // "Me gusta JavaScript"
slice()
Extraer parte del string
let texto = "JavaScript";
texto.slice(0, 4); // "Java" texto.slice(4); // "Script"
substring()
Similar a slice() pero no acepta negativos
let texto = "JavaScript";
texto.substring(0, 4); // "Java"
repeat()
Repetir string
let texto = "Hola";
texto.repeat(3); // "HolaHolaHola"
✅

Validación y Comprobación

isNaN()
Verificar si NO es un número
-
isNaN("123"); // false isNaN("abc"); // true isNaN("123abc"); // true
typeof
Verificar tipo de dato
-
typeof "hola"; // "string" typeof 123; // "number" typeof true; // "boolean"
length
Obtener longitud del string
let texto = "Hola";
texto.length; // 4
String()
Convertir a string explícitamente
let numero = 456;
String(numero); // "456"
🛠️

Utilidades y Conversión

split()
Dividir string en array
let texto = "manzana,naranja,plátano";
texto.split(","); // ["manzana", "naranja", "plátano"]
concat()
Concatenar strings
let str1 = "Hola"; let str2 = "Mundo";
str1.concat(" ", str2); // "Hola Mundo"
charAt()
Obtener carácter en posición específica
let texto = "JavaScript";
texto.charAt(0); // "J" texto.charAt(4); // "S"
charCodeAt()
Obtener código Unicode del carácter
let texto = "A";
texto.charCodeAt(0); // 65
padStart()
Rellenar al inicio
let texto = "5";
texto.padStart(3, "0"); // "005"
padEnd()
Rellenar al final
let texto = "Hola";
texto.padEnd(10, "-"); // "Hola------"
⚡

Métodos Modernos (ES6+)

Template Literals
Strings con variables y multi-línea
let nombre = "Ana"; let edad = 25;
`Hola ${nombre}, tienes ${edad} años`; // "Hola Ana, tienes 25 años"
String.raw()
String raw sin escapar caracteres
-
String.raw`Hola\nMundo`; // "Hola\\nMundo" (no salto de línea)
match()
Buscar coincidencias con regex
let texto = "El precio es $100";
texto.match(/\d+/); // ["100"]
matchAll()
Todas las coincidencias con regex
let texto = "a1 b2 c3";
[...texto.matchAll(/\d/g)]; // [["1"], ["2"], ["3"]]
codePointAt()
Código Unicode para caracteres UTF-16
let texto = "😀";
texto.codePointAt(0); // 128512
