🎨 Variables CSS y Fuentes Personalizadas

/* Definición de fuentes personalizadas */ @font-face { font-family: "Alan Sans"; src: url(Alan_Sans/AlanSans-VariableFont_wght.ttf); } /* Variables CSS (Custom Properties) */ :root { --color-fondo: #F5F7FF; --color-fondonavegacion: rgba(1, 37, 125); --color-footer: #2272FF; }
💡 Variables CSS: Permiten reutilizar valores en todo el código. Se definen en :root para acceso global.
✅ Ventaja: Si cambias el color en la variable, se actualiza automáticamente en todos los lugares donde se use.

📐 Grid Layout - Estructura Principal

body { display: grid; grid-template-columns: 0.3fr 1fr; grid-template-rows: 1fr 1fr; grid-template-areas: "header header" "nav nav" "aside main" "footer footer"; }

Explicación del Grid:

  • grid-template-columns: 0.3fr 1fr - Dos columnas (30% y 70%)
  • grid-template-areas - Define áreas con nombres semánticos
  • "header header" - Header ocupa ambas columnas
  • "aside main" - Aside en columna 1, Main en columna 2
Visualización del Layout:
┌───────────────────┐
│ HEADER │ ← Ocupa 2 columnas
├───────────────────┤
│ NAV │ ← Ocupa 2 columnas
├───────┬───────────┤
│ ASIDE │ MAIN │ ← Aside (30%), Main (70%)
├───────┴───────────┤
│ FOOTER │ ← Ocupa 2 columnas
└───────────────────┘

📍 Position Sticky y Fixed - Navegación Pegajosa

/* Header sticky - Se pega al hacer scroll */ header { position: sticky; top: 0px; z-index: 11; } /* Nav fixed - Siempre visible */ nav { position: fixed; top: 80px; /* Justo debajo del header */ z-index: 10; }
💡 Diferencia: sticky se comporta como relative hasta llegar al top, luego se vuelve fixed. fixed siempre está fijo en la ventana.
✅ z-index: Controla el orden de apilamiento. Mayor número = más al frente.

🎯 Flexbox - Alineación y Distribución

/* Centrado perfecto con Flexbox */ header { display: flex; align-items: center; justify-content: center; } /* Navegación horizontal */ nav ul { display: flex; gap: 40px; }

Propiedades Flexbox usadas:

  • display: flex - Activa flexbox
  • align-items: center - Centra verticalmente
  • justify-content: center - Centra horizontalmente
  • gap: 40px - Espacio entre elementos

🛍️ Grid para Cartas de Productos

.cartas { display: grid; grid-template-columns: repeat(3, 1fr); gap: 32px; } /* Estilos diferentes para pares e impares */ .cartaproducto:nth-child(odd) { border: 3px solid #FF6B6B; box-shadow: 4px 4px 16px rgba(255, 107, 107, 0.6); } .cartaproducto:nth-child(even) { border: 3px solid #64FFDA; box-shadow: 4px 4px 16px rgba(100, 255, 218, 0.6); }
✅ repeat(3, 1fr) crea 3 columnas del mismo tamaño (1 fracción cada una).
💡 nth-child(odd/even): Selectores que apuntan a elementos pares o impares, perfecto para crear patrones de colores.

✨ Efectos y Transiciones

/* Efecto hover en enlaces */ nav ul li a { transition: color 0.3s ease; } nav ul li a:hover { color: coral; } /* Efecto active en imágenes */ .imagen-contenedor img:active { filter: sepia(); } /* Mostrar información al hover */ .info-promocion { display: none; } .imagen-contenedor:hover .info-promocion { display: block; }

Pseudo-clases usadas:

  • :hover - Cuando el mouse pasa por encima
  • :active - Cuando el elemento está siendo clickeado
  • :nth-child() - Para elementos específicos en una lista

📱 Diseño Responsivo - Media Queries

@media (max-width: 576px) { body { grid-template-columns: 1fr; grid-template-areas: "header" "nav" "main" "aside" "footer"; } .cartas { grid-template-columns: 1fr; } /* Menú hamburguesa */ .burgesasinpatatas { display: block; } }
💡 Mobile First: El diseño se adapta a pantallas pequeñas cambiando el grid a una sola columna.

Características del menú hamburguesa:

  • display: none - Oculto en desktop
  • display: block - Visible en móvil
  • flex-direction: column - Menú vertical en móvil

📊 Tablas y Columnas CSS

/* Diseño de columnas para el aside */ aside .sostenibilidad { column-count: 2; column-gap: 30px; } /* Estilos de tabla */ .tabla-productos { border-collapse: collapse; border-radius: 12px; } .tabla-productos tr:hover { background: #333; }
✅ border-collapse: collapse elimina el espacio entre bordes de tabla, creando líneas continuas.

⚡ Conceptos CSS Avanzados Usados

1. Especificidad y Herencia

  • Variables CSS para mantenimiento fácil
  • Selectores descendientes como `.imagen-contenedor:hover .info-promocion`
  • !important implícito a través de especificidad

2. Modelo de Caja

  • box-sizing: border-box incluido globalmente
  • padding, margin, border para espaciado
  • border-radius para esquinas redondeadas

3. Unidades de Medida

  • px - Para valores fijos
  • % - Para dimensiones relativas
  • fr - Unidades de grid
  • vh/vw - Viewport height/width
  • rem/em - Para tipografía responsive
🎯 Conclusión: Este código demuestra un uso avanzado de CSS Grid, Flexbox, variables, y diseño responsive, siguiendo las mejores prácticas modernas.
