Propiedad Position

La propiedad position especifica el método de posicionamiento para un elemento.

static
Valor por defecto. El elemento se posiciona según el flujo normal del documento.
static
relative
Se posiciona relative a su posición normal. Se puede ajustar con top, right, bottom, left.
relative
absolute
Se posiciona relative al ancestro posicionado más cercano (no static).
absolute
fixed
Se posiciona relative a la ventana del navegador. Permanece fijo al hacer scroll.
fixed

Este elemento está posicionado fixed en la esquina inferior derecha.

sticky
Se comporta como relative hasta que cruza un punto específico, entonces se comporta como fixed.
sticky

box-sizing

El width y height solo incluyen el contenido. Padding y border se añaden al ancho total.
border-box
El width y height incluyen contenido, padding y border. El tamaño total es el especificado.

content-box

Flexbox

Flexbox es un modelo de diseño unidimensional para distribuir espacio entre elementos.

.container {
display: flex;
justify-content: center; /* Alineación horizontal */
align-items: center; /* Alineación vertical */
flex-direction: row; /* Dirección de los elementos */
}

Más detalles sobre Flexbox en otra guía específica.

CSS Grid

CSS Grid es un sistema de diseño bidimensional para crear diseños complejos.

.container {
display: grid;
grid-template-columns: 1fr 1fr 1fr; /* Tres columnas de igual ancho */
grid-template-rows: 100px auto; /* Dos filas */
gap: 10px; /* Espacio entre celdas */
}

Revisa nuestra guía específica de Grid para más detalles.
