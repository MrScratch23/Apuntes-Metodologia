🔤 Strings y Validación en PHP

Guía completa de funciones para manipulación y validación de texto

✅

Validación y Comprobación

is_numeric()
Verificar si variable es numérica
-
is_numeric("123"); // true is_numeric("12.3"); // true is_numeric("abc"); // false is_numeric("123abc"); // false
is_string()
Verificar si variable es string
-
is_string("hola"); // true is_string(123); // false is_string(true); // false
empty()
Verificar si variable está vacía
-
empty(""); // true empty("hola"); // false empty(0); // true empty(null); // true
isset()
Verificar si variable existe y no es null
-
$var = "valor"; isset($var); // true isset($noExiste); // false
ctype_digit()
Verificar si todos los caracteres son dígitos
-
ctype_digit("123"); // true ctype_digit("12.3"); // false ctype_digit("123a"); // false
filter_var()
Filtrar y validar variable
-
filter_var("test@email.com", FILTER_VALIDATE_EMAIL); // "test@email.com" filter_var("invalid", FILTER_VALIDATE_EMAIL); // false
🔄

Conversión de Case

strtoupper()
Convertir a MAYÚSCULAS
$texto = "Hola Mundo";
strtoupper($texto); // "HOLA MUNDO"
strtolower()
Convertir a minúsculas
$texto = "Hola Mundo";
strtolower($texto); // "hola mundo"
ucfirst()
Primera letra en mayúscula
$texto = "hola mundo";
ucfirst($texto); // "Hola mundo"
ucwords()
Primera letra de cada palabra en mayúscula
$texto = "hola mundo php";
ucwords($texto); // "Hola Mundo Php"
mb_strtoupper()
strtoupper para caracteres multibyte (UTF-8)
$texto = "café ñandú";
mb_strtoupper($texto, 'UTF-8'); // "CAFÉ ÑANDÚ"
🔍

Búsqueda en Strings

strpos()
Encontrar posición de substring
$texto = "Bienvenido a PHP";
strpos($texto, "PHP"); // 13 strpos($texto, "Java"); // false
str_contains()
Verificar si contiene substring (PHP 8+)
$texto = "Aprendiendo PHP";
str_contains($texto, "PHP"); // true str_contains($texto, "Java"); // false
str_starts_with()
Verificar si comienza con substring (PHP 8+)
$texto = "Hola Mundo";
str_starts_with($texto, "Hola"); // true str_starts_with($texto, "Mundo"); // false
str_ends_with()
Verificar si termina con substring (PHP 8+)
$texto = "archivo.php";
str_ends_with($texto, ".php"); // true str_ends_with($texto, ".js"); // false
substr()
Extraer parte del string
$texto = "JavaScript";
substr($texto, 0, 4); // "Java" substr($texto, 4); // "Script"
✂️

Modificación de Strings

trim()
Eliminar espacios en blanco al inicio y final
$texto = " hola mundo ";
trim($texto); // "hola mundo"
str_replace()
Reemplazar texto
$texto = "Me gusta Java";
str_replace("Java", "PHP", $texto); // "Me gusta PHP"
strlen()
Obtener longitud del string
$texto = "Hola";
strlen($texto); // 4
substr_replace()
Reemplazar parte del string
$texto = "ABCDEFG";
substr_replace($texto, "123", 2, 3); // "AB123FG"
str_repeat()
Repetir string
$texto = "Hola";
str_repeat($texto, 3); // "HolaHolaHola"
📝

Formateo y Output

sprintf()
Formatear string con placeholders
-
sprintf("Hola %s, tienes %d años", "Ana", 25); // "Hola Ana, tienes 25 años"
number_format()
Formatear números
$numero = 1234.5678;
number_format($numero, 2, ',', '.'); // "1.234,57"
htmlspecialchars()
Convertir caracteres especiales a entidades HTML
$texto = "";
htmlspecialchars($texto); // "<script>alert('xss')</script>"
nl2br()
Convertir saltos de línea a tags <br>
$texto = "Línea 1\nLínea 2";
nl2br($texto); // "Línea 1<br>Línea 2"
🛠️

Utilidades Adicionales

explode()
Dividir string en array
$texto = "manzana,naranja,plátano";
explode(",", $texto); // ["manzana", "naranja", "plátano"]
implode() / join()
Unir array en string
$array = ["PHP", "es", "genial"];
implode(" ", $array); // "PHP es genial"
str_shuffle()
Mezclar caracteres aleatoriamente
$texto = "abcdef";
str_shuffle($texto); // "cbafed" (aleatorio)
str_pad()
Rellenar string a longitud específica
$texto = "Hola";
str_pad($texto, 10, "-", STR_PAD_BOTH); // "---Hola---"
str_word_count()
Contar palabras en string
$texto = "Hola mundo PHP";
str_word_count($texto); // 3
